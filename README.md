# IT207Workshop
A repository for the IT207 class project.
During the workshop, I created the Find First function, ff.js.
It is run using the command node ff.js <PATTERN> <FILENAME> <NUMBER_OF_LINES>
It combines the Linux grep and head commands to search the first N number of arguments for matching situations.

I asked AI to explain to me the grep, head, and tail commands. I also asked AI to generate me a test log for testing purposes, as well as to review, debug and consider edge cases not covered by the file.
AI helped collate research results, generate random information for proof-of-concept, and bring up edge cases that helped refine some missing details of the program file.
I had to think independently to parse the edge case suggestions, as well as in problem solving to assemble the code itself.
The AI was wrong primarily in the edge cases and suggestions, such as suggesting I did not have a test file when I did, or by finding problems with edge cases that were already accounted for in the code.
